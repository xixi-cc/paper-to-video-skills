# Paper to Video Skills

我用这套 Skills 把论文整理成 Beamer 幻灯片，再配上旁白做成视频。主要用于物理和 AI 论文的阅读与分享，适配 Codex 和 WSL/Linux。

流程很简单：**论文 PDF / arXiv → 幻灯片 → 配音视频**。可以只做幻灯片，也可以继续制作视频；上传 B 站是单独的可选步骤。
